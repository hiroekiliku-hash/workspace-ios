# 隐私与公开源码边界

仓库只包含客户端代码、图标、语言资源、虚构演示内容和测试，以新的 Git 历史发布。不包含原私有仓库历史、用户归档、数据库、缓存、日志、真实账户、签名证书、开发团队标识、APNs 密钥、SSH 凭据、服务器配置或部署工作流。示例姓名与场景已泛化；设备介绍不针对个人的特定型号。

这是发布时的源码整理说明，不是“不可能存在隐私问题”的保证。提交 Issue、截图、课程 JSON 或崩溃日志前，请移除姓名、邮箱、令牌、日程和文件路径。不要向公开 Issue 粘贴密钥。

## 使用时的数据

本地事项、偏好、课程缓存和附件保存在设备内；登录凭据使用系统 Keychain。系统通知、系统日历与 App Group 的共享数据由相应系统能力处理。归档可包含日程与附件，导出后应视为私人文件，自行决定是否加密和分享。

默认构建使用 `https://example.invalid`，不连接原作者的生产服务。配置自己的后端并使用登录/同步后，登录信息、事项、课程、答案、进度以及相应设备信息可能按操作发送到该后端。公共内容检查不带账户令牌，账户 API 与课程服务使用同一个构建配置的服务根地址。改变服务地址前应确认数据接收方。

课程真实运行是单独的操作：启用兼容 Python/C++ 运行服务时，提交的源码和标准输入会发送到该服务。不要把密码、密钥或私人数据放入练习源码。仅展示课程不会自动执行 Python/C++。

演示数据是虚构样例；演示模式使用隔离状态，不应用于保管真实记录。开源仓库没有访问任何人现有账户的权限，也不提供公共服务器的使用承诺。
